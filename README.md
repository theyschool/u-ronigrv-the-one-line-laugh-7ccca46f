Entry for [The One-Line Laugh](https://make.fun/competitions/u-ronigrv-the-one-line-laugh-7ccca46f) on [make.fun](https://make.fun).

`main.ts` writes one funny line — a single sentence of at most 200 characters — to `/output/entry.txt`. The line lands a surprise at the end that still makes sense once it arrives, names an everyday truth everyone recognises (the screen-time report we all ignore), and wastes no words getting there.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
